# 🏍️ موتو ستور — متجر إلكتروني للموتوسيكلات وقطع الغيار

متجر إلكتروني متكامل واحترافي ومتجاوب (RTL عربي) متخصص في بيع الموتوسيكلات وقطع الغيار والإكسسوارات والمستلزمات.

## المميزات

- 🏠 **صفحة رئيسية** احترافية (Banner، أقسام، منتجات مميزة، أحدث المنتجات، عروض وخصومات).
- 🛍️ **صفحة المنتجات** مع بحث وفلاتر (تصنيف، شركة، موديل، السعر، التوفر) وترتيب (الأحدث، السعر، الأكثر مبيعًا) و Pagination.
- 🗂️ **صفحة التصنيفات** (16 تصنيفًا قابلة للإدارة من لوحة التحكم).
- 🏭 **قطع الغيار حسب الموتوسيكل**: Honda → CBR، Yamaha → R1، SYM → Symphony، Bajaj → Boxer، وغيرها (شركات وموديلات قابلة للإدارة).
- 📄 **صفحة تفاصيل المنتج** (صور متعددة، مواصفات، توافق، كمية، منتجات مرتبطة، Structured Data).
- 🛒 **سلة تسوق** كاملة (زيادة/نقصان الكمية، حذف، إجمالي تلقائي) محفوظة في LocalStorage.
- 💳 **إتمام الطلب** مع بيانات المشتري وملخص الطلب وتكلفة الشحن.
- 📲 **الدفع**: InstaPay أو المحفظة الإلكترونية (01055325632) مع رفع Screenshot لإثبات الدفع ورقم العملية.
- 🔐 **لوحة إدارة** محمية بمصادقة حقيقية (JWT + scrypt) لإدارة المنتجات والتصنيفات والشركات والموديلات والطلبات.
- 🖼️ **رفع صور** آمن (تحقق من النوع والحجم والامتداد و Magic Bytes).
- 🛡️ **أمان**: Server-side validation، معاملات SQL آمنة، حماية Admin APIs، عدم تخزين أسرار في الواجهة.

## الـ Stack

| الطبقة | التقنية |
|--------|---------|
| Backend | Node.js (وحدات مدمجة فقط — بدون أي اعتماديات خارجية) |
| HTTP Server | `node:http` |
| Database | SQLite عبر `node:sqlite` |
| المصادقة | JWT (HMAC-SHA256) + scrypt لتشفير كلمات المرور |
| رفع الملفات | Multipart parser مكتوب يدويًا + تحقق Magic Bytes |
| Frontend | Vanilla JS (ES Modules) + HTML + CSS — RTL متجاوب |

> **لا يحتاج المشروع `npm install`** — يعمل مباشرة بـ Node.js 22.5+ (يستخدم `node:sqlite` المدمج).

## متطلبات التشغيل

- **Node.js 22.5 أو أحدث** (يفضل 23+). تحقق بـ `node --version`.

## طريقة التشغيل محليًا

1. **انسخ ملف البيئة** (اختياري):
   ```bash
   copy .env.example .env
   ```

2. **شغّل الخادم**:
   ```bash
   node server/index.js
   ```
   أو عبر npm:
   ```bash
   npm start
   ```

3. **افتح المتصفح** على: <http://127.0.0.1:3000>

## متغيرات `.env`

| المتغير | الوصف | الافتراضي |
|---------|-------|-----------|
| `PORT` | منفذ الخادم | `3000` |
| `HOST` | عنوان الاستماع | `127.0.0.1` |
| `JWT_SECRET` | سر توقيع الـ JWT (غيّره في الإنتاج!) | عشوائي |
| `ADMIN_USERNAME` | اسم مستخدم الإدارة | `admin` |
| `ADMIN_PASSWORD` | كلمة مرور الإدارة | `admin123` |
| `WALLET_NUMBER` | رقم المحفظة الإلكترونية | `01055325632` |

## بيانات الدخول للوحة الإدارة (تجريبي)

- **الرابط**: <http://127.0.0.1:3000/#/admin>
- **اسم المستخدم**: `admin`
- **كلمة المرور**: `admin123`

> ⚠️ غيّر كلمة المرور و`JWT_SECRET` قبل النشر في بيئة إنتاج حقيقية.

## ملاحظات حول الدفع

- لا يوجد تكامل مباشر مع InstaPay (لا توجد API رسمية عامة). الدفع يتم يدويًا عبر التحويل ثم رفع Screenshot، ويُراجع من لوحة الإدارة.
- نظام الدفع مصمم كـ **abstraction** بحيث يمكن لاحقًا إضافة Payment Gateway حقيقي (مثل Paymob/Stripe) دون تغيير باقي النظام.

## الأمان

- كلمات المرور مشفرة بـ `scrypt` (Salt عشوائي).
- جلسات الإدارة عبر JWT موقّع بـ HMAC-SHA256 في Cookie (HttpOnly + SameSite).
- جميع Admin APIs محمية Server-side (لا تعتمد على إخفاء الرابط).
- التحقق من المدخلات Server-side، واستعلامات SQL عبر Prepared Statements (منع SQL Injection).
- رفع الملفات: تحقق من الامتداد + نوع MIME + Magic Bytes + حجم الملف.
- لا توجد أسرار أو API Keys في الواجهة الأمامية.
